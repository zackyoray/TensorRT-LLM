# Context Awareness and Rules

Author: Mark Jacobson <mjacobson>, ideas sourced from various forum posts, guides, etc.

The AI losing the context and starting to thrash is a common problem. The AI not following the rules is another issue faced over time. The emoji rule is a simple way of knowing when the AI has lost the context/rules. When I no longer see the animal emojis show up in the chat, I know the AI has lost the context/rules and I should start a new chat window.

The "comprehensive rule application" section is perhaps overkill, but it was frustrating having the AI not follow the rules.

Primarily used with claude-3.7-sonnet on Cursor versions 0.46.x-0.48.x
