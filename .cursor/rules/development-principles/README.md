# Development Principles

Author: Mark Jacobson <mjacobson>, ideas sourced from various forum posts, guides, etc.

The inclusion of YAGNI / SOLID / KISS / DRY rule was a common tip found online.

I am less confident about the Efficiency Principles section. I had the AI create this set of rules one time after it started thrashing. The simple script went from a multi-minute runtime to less than 2 seconds, though I am not sure if it's because I refreshed the context (which included a bunch of domain specific rules). I think that something like this is a good general starting point regardless of the language, but it could be best practice to define a similar ruleset that is a bit more specialized for the specific languages/frameworks/project. Very specific project guidance could go into the project requirement documentation (.md) rather than being a rule.

Primarily used with claude-3.7-sonnet on Cursor versions 0.46.x-0.48.x
