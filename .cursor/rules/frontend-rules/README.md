# 35 Frontend Rules

MDC rules for 35 frontend development and best practices.

## Overview

This directory contains MDC rules for frontend development, including frameworks, build tools, and UI libraries.

## MDC Rules

| Rule File | Description |
|-----------|-------------|
| [angular.mdc](./angular.mdc) | Angular framework rules for building scalable web applications with TypeScript and component architecture. |
| [eslint.mdc](./eslint.mdc) | ESLint rules for maintaining code quality and consistency in JavaScript and TypeScript projects. |
| [graphql.mdc](./graphql.mdc) | GraphQL API integration rules for efficient data fetching and modern API development. |

| [react.mdc](./react.mdc) | Comprehensive guide to React best practices, covering code organization, performance, security, testing, and common pitfalls. Adhering to these guidelines helps developers build maintainable, scalable, and high-performing React applications. |

## Usage

These MDC rules are automatically applied by Cursor when working with matching file types.

To use these rules:
1. Ensure the MDC rules are in your project
2. The rules will apply based on their glob patterns
3. Check individual `.mdc` files for specific patterns and behaviors
